# Barcode Scanner & Report Generator

Приложение для сканирования и регистрации товаров с EAN-13 и акцизными марками, с автоматической генерацией QR-кодов и формированием отчетов в Excel.

## Описание

Desktop-приложение для автоматизации процесса регистрации товаров через сканирование штрихкодов (EAN-13) и акцизных марок. Приложение проверяет уникальность акцизных марок, генерирует QR-коды, сохраняет данные в базу данных SQL Server и формирует отчеты в Excel с встроенными QR-кодами.

## Основные возможности

- **Сканирование EAN-13** с автоматической проверкой формата и дополнением до 13 цифр
- **Ввод акцизных марок** (длина 68 или 150 символов)
- **Автоматическая проверка уникальности** акцизных марок в БД
- **Генерация QR-кодов** для акцизных марок
- **Сохранение данных** в Microsoft SQL Server
- **Формирование Excel-отчетов** с встроенными QR-кодами
- **Индикатор состояния подключения** к базе данных
- **Смена темы оформления** (темная/светлая)
- **Автоматическое переключение раскладки** клавиатуры на EN
- **Всплывающие уведомления** о статусе операций
